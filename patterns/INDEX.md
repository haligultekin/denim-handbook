# Pattern Archive

This directory is the storage location for all physical and digital pattern files related to the Denim Handbook.

## Accepted Formats
- **.PDF**: Print-at-home (A4/Letter) or A0 copyshop formats.
- **.SVG / .DXF**: Vector files for modification in CAD software, Adobe Illustrator, or open-source editors.

*Drop your pattern files here before committing to the repository.*
